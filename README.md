# B站倍速浏览器

面向 Android 16（API 36）的轻量 WebView 浏览器，启动默认打开 `https://www.bilibili.com/`。使用 B 站官方电脑端网页与播放器，默认提供适合手机的触屏布局，底部「设置」统一管理倍速与浏览选项。

[下载已发布 APK](https://github.com/GodBook/bilispeed-android/releases/latest) · [源码](https://github.com/GodBook/bilispeed-android)

当前正式版本为 **[1.3.1 / versionCode 16](https://github.com/GodBook/bilispeed-android/releases/tag/v1.3.1)**，公开 APK 已覆盖安装连接手机并核对哈希。竖屏控制条和进度条约 3 秒无操作后自动隐藏，单击画面唤出或收起；拖动与打开设置面板时保持显示。细进度轨道、统一图标、按钮按压反馈和轻量面板动效让触摸操作更自然，保留完整点击区域并支持减少动态效果。修正长标题下授权说明与操作栏重叠。沿用统一主题、列表保位、五项底部导航、顶部搜索、列表下拉刷新和全屏连续切集。手机实测范围、失败记录及正式附件校验见 [VALIDATION.md](VALIDATION.md)。

## 安装与使用

从[最新 Releases](https://github.com/GodBook/bilispeed-android/releases/latest)下载APK，传到手机后覆盖安装；如系统询问，允许当前文件管理器安装此APK。无需root，也不会替换官方B站App。已有1.1.x或1.2.x可在应用内检查更新；已有1.0.0时先手动覆盖安装，即可获得在线更新入口。

1.3.1 使用原签名，可以覆盖安装旧版，保留设置与已有 Cookies。本机安装包位于 `artifacts/BiliSpeed-1.3.1-Android16.apk`。

本版的连接手机、回归和正式包验证结果见 VALIDATION.md；复现命令见 DEVICE-TESTING.md。Android 16 模拟器结果保留在历史版本记录中。

- 点底部「我的」右侧的「设置」，直接选择 1x、1.25x、1.5x、2x、2.5x、3x、3.5x、4x、5x。
- 滑杆支持 0.25–5x，步长 0.05；输入框支持两位小数，例如 2.75x。
- 默认记住上次选择；关闭「记住上次倍速」后，下次启动恢复 1x。
- 移除旧三点和倍速浮钮的视图及拖动路径，不遮挡网页和评论。播放栏内的倍速按钮显示当前速度，竖屏和全屏均可直接调节；与底部「设置」双向同步。
- 设置按「播放 / 浏览与外观 / 常用工具 / 关于与更新」分组，支持即时修改、自动保存、输入校验、系统返回键和返回浏览；关闭后保留原网页的播放与滚动位置。
- 「设置 → 字幕按钮外观」可调整触屏字幕按钮的大小（70–150%）与不透明度（20–100%），支持即时预览和恢复默认。
- 底部「首页 / 热门 / 动态 / 我的 / 设置」提供常用入口；搜索使用首页顶部搜索栏。点击「我的」直接显示个人页。登录后显示实际头像、昵称、等级、B币、硬币、动态、关注和粉丝；未登录时显示登录入口，网络失败时可重试。
- 首页回到顶部后下拉，松手刷新并显示加载指示；普通滚动、未达到距离的下拉不刷新，加载期间不会重复触发。热门、动态列表也支持下拉刷新；「我的」只重新请求账号资料并尽量保留已有内容。视频页、输入编辑、弹窗及内部滚动区域不触发列表刷新；打开设置或进入全屏时停止下拉刷新。触屏首页隐藏大型轮播推荐，直接展示双列视频；电脑原版布局保留官网原貌。
- 底部切换网页入口时优先复用已有历史并恢复位置；再次点击当前列表入口只滚回顶部，需要换内容时下拉刷新。视频返回列表时按链接/滚动锚点恢复，书签有数量和大小上限；官网更新推荐或低内存回收文档时可能重新加载并恢复到附近位置。
- 「设置 → 浏览与外观 → 应用主题」支持跟随系统、浅色、深色，新安装默认跟随系统。「我的」月亮按钮控制同一偏好，旧夜间设置自动迁移。主题覆盖原生界面和主要触屏网页，切换不重载视频，不反转封面、头像、视频与弹幕颜色。
- 首页和搜索视频列表按两列展示；视频页把播放器放到上方并铺满宽度，推荐栏纵向排列；「简介 / 评论 / 选集」可直接跳到对应内容。
- 简介和评论未加载时，对应入口置灰，内容稍后加载后自动恢复。选集读取官方视频数据，分 P 和合集分开展示，显示当前集、序号与时长，长标题最多两行。长列表默认显示当前集附近的五集，支持展开全部、收起和定位当前集；点击打开对应官方视频及分 P。超过一小时显示时:分:秒。选集加载失败时提供重试，快速换视频不会被旧请求覆盖。
- 官方网页仍在初始化时，自定义播放栏、内容入口和选集等待官方 Vue 根组件真正挂载后再插入，避免评论区初始化被打断；官方脚本明确加载失败时保留延迟兜底。HTTP 图片资源自动升级为 HTTPS，补全 UP 主头像和组件声明的懒加载图片，保持原有混合内容限制。
- 触屏播放栏提供暂停 / 继续、进度滑杆、播放时间、上一集 / 下一集、倍速、音量、字幕和全屏入口；直接控制官方 HTML5 视频，不依赖电脑端悬停控件是否加载。切集优先在当前分 P 内进行，到边界后衔接合集相邻视频；缺少相邻集时置灰，单个视频隐藏切集按钮。横竖屏按钮均为一行，竖屏音量与字幕从「更多」打开，320px 窄屏显示当前播放时间，完整时长仍可从进度说明读取。「更多 → 画质」显示官网可选项，调用官方菜单，并等待实际画质反馈；保留播放位置、倍速与全屏。登录、会员、购买和地区权限由官网判断，失败时保留当前播放并可重试。
- 播放栏倍速面板支持 0.25–5x 预设和两位小数的自定义速度，沿用「记住上次倍速」设置；全屏内选择倍速保持全屏，打开面板时播放栏不会自动隐藏。全屏切集保持 Android 横屏和沉浸显示，新页面中的官方播放器铺满屏幕；点击「退出」或系统返回退出全屏，离开当前视频或加载失败时清理全屏状态。
- 在视频画面上单指左右滑动可预览进度，松手后跳转；一次横跨画面的滑动最多调节 120 秒。上下滑动仍可滚动页面，双指操作或手势取消不会跳转；直播不提供进度跳转。
- 单指快速双击视频画面可暂停 / 继续播放，竖屏和全屏均适用。单击用于显示或收起控件；滑动、双指、长按和取消手势不会识别成双击。
- 「音量」面板支持 0–100% 调节和静音 / 恢复；「字幕」面板支持选择视频已有字幕语言或关闭字幕，兼容 HTML5 字幕轨道和官方播放器的主字幕菜单。无字幕或需登录时会显示说明，字幕权限由官方网页决定。
- 竖屏播放栏与进度条约 3 秒无操作自动隐藏，轻点画面显示，再次点击可收起；全屏默认隐藏并使用相同手势。拖动滑杆、按住当前进度点、使用键盘或打开设置面板时保持显示，操作结束后重新计时。隐藏时也可以左右滑动调节进度。控件、字幕避让和面板使用轻量动效，系统减少动态效果时关闭动画。
- 播放器根据视频比例和可用屏幕高度调整尺寸，横竖屏切换时重新计算，画面按比例完整显示；触屏布局按手机宽度显示，电脑原版布局保留双指缩放。
- 「设置」可刷新页面、打开链接 / BV 号、复制链接、使用系统浏览器，或切换「手机触屏布局 / 电脑原版布局」。两种布局均使用电脑端，原版布局支持双指缩放并保留底部导航。首页使用底部入口，后退使用系统返回键。
- 官方 App 的分享链接也可以分享给本浏览器。
- 「打开链接」支持粘贴完整分享文本、短链接或 BV 号，自动提取网址；HTTP 链接会升级为 HTTPS。手机端首页、视频、番剧、搜索、动态和空间链接会转到对应电脑端，并保留分 P、播放时间等参数。
- 全屏时隐藏底部导航和浮动按钮；系统返回键先退出全屏，再返回上一页。设置页打开时，返回键优先关闭设置。
- 系统恢复页面时保留倍速；页面历史状态超过 256 KiB 时保留当前 HTTPS 链接并重新加载，避免切后台崩溃。
- 网页渲染进程退出时保留应用、当前 HTTPS 链接、倍速和已有 Cookies，显示「重新加载」入口；失效的全屏和文件选择请求会退出。尚未点击重试时切后台，仍会保存待恢复的链接。
- 触屏布局与倍速控制过滤播放控件、字幕和弹幕的频繁变化；全屏控件隐藏时停止更新不可见的进度文字和无障碍属性，显示时同步。倍速与前后台状态通过小消息更新，页面缺少脚本时才完整注入；切到后台时停止排版与字幕观察，返回后重新发现播放器和同步控件。
- B 站网页可按播放器设置自动播放，切到后台会持续暂停视频，并阻止延迟播放和新视频自动播放；返回后可手动继续。其他网站保持手动触发播放。
- 升级后即使旧版设置为手机网页，也会使用电脑端；倍速、字幕外观与已有 Cookies 沿用。旧版浮钮位置偏好保留，但本版不显示浮钮。
- 「我的」的登录、编辑资料、空间、历史记录、我的收藏和稍后再看继续打开官方页面。登录表单优先展示密码和短信登录，适合在同一部手机上操作。个人页使用统一主题；「离线缓存」入口直接标注暂不支持，点击可查看说明。
- 历史记录按日期分组，网格按两列展示，支持官方的列表切换、筛选、搜索与批量管理入口。兼容 `/account/history` 跳转到 `/history`，底部「我的」保持选中。
- 收藏夹使用可展开菜单，选择后收起并显示当前收藏夹；收藏视频双列排列，保留官方搜索、筛选和管理。稍后再看的工具栏、空状态与网格/列表适合手机宽度。
- 动态适配登录后的主栏、分类与 UP 主列表，内容、视频卡片、转发、评论和点赞入口留在屏内；详情页评论同步适配。空间导航横向滚动并定位当前栏目，首页、投稿、关注/粉丝、追番、分页和空间设置适合手机操作。
- 「离线缓存」说明与「打开视频链接」弹窗打开时，系统返回键先关闭弹窗，再次返回才离开「我的」。
- 首页顶部沿用官方搜索栏。打开链接结束或取消后收起键盘并恢复焦点；切换底部入口时结束原输入，避免键盘继续挤压页面和设置。
- 个人中心的侧栏改为横向滑动菜单，资料、经验、每日奖励与昵称表单按手机宽度排列。官方弹幕设置面板保持在屏幕内，超出可用高度时可滚动；基础 / 高级选项完整展示，点「完成」、再次点弹幕设置图标或点面板外可关闭。

## 在线更新

点「设置 → 检查更新」，应用从本项目 GitHub Releases 获取最新正式版本，显示版本、大小和更新说明。确认后下载 APK，检查完整性与原签名，再打开 Android 系统安装器。

首次更新需要允许「B站倍速浏览器」安装应用：按提示进入系统设置，开启后返回，继续安装已下载版本。安装仍需系统确认；覆盖安装保留倍速、外观与网页登录状态。取消安装后，可再次从设置继续。

启动检查默认开启，成功检查后 24 小时内不重复检查；失败后可在下次进入应用时重试，自动重试间隔至少 15 分钟。发现新版只提示，不自动下载。可在「设置 → 启动时检查更新」关闭。检查和下载要求手机网络能够访问 GitHub；失败时可以手动重试或打开发布页下载。取消操作会停止后续请求。应用自动清理旧更新包和未完成下载，保留待安装版本。

更新渠道为本仓库 Releases 中的 update.json，不用 GitHub 登录，也没有自建更新服务器。只接受版本号递增、包名一致、SHA-256 和文件大小匹配、签名与当前应用完全相同的 APK。拒绝 HTTP、第三方下载地址和不受信任的跳转；APK 下载到应用私有目录。

## 实际范围

这是个人第三方浏览器。内容、账号操作和播放器沿用官方电脑端网页，以网页排版和原生导航尽量接近手机操作。动态、个人中心等仍取决于官方网页的能力；不提供原生 App 的离线缓存或后台播放。网页的「打开 App」跳转会被拦截，能解析的视频链接会在网页打开。会员、付费和地区限制仍按 B 站账号权限执行。

触屏排版覆盖首页、热门、搜索、视频、历史记录、收藏、稍后再看、动态及个人空间等主要入口；其他官方页面可以在「设置」关闭「手机触屏布局」查看。官方网页调整结构后可能需要更新适配脚本。真实账号资料、历史和收藏已在本机检查；发布评论、删除记录和修改隐私等账号写操作未在真实账号执行。

倍速控制直接作用于 HTML5 视频，保留音调；页面重新设置速度、换视频、加载新播放器时会重新应用所选值。播放栏倍速面板与原生设置使用同一选择；官方电脑端自带倍速菜单会被该选择覆盖。直播保持 1x。5x 对网络、设备解码和播放器有更高要求；网站将来改动播放器后，可能需要更新控制脚本。

登录沿用官方网页，Cookies 保存在本机应用数据中。应用申请联网、网络状态和安装更新权限；不读取官方 App 数据，不上传账号信息到自建服务，不绕过视频权限。安全证书出错时停止加载。网页与原生层的消息接口仅向 HTTPS B 站域名开放，没有可访问文件或执行系统命令的 JavaScript 接口。网页不能触发原生更新或安装。

## 构建

安装 JDK 17–24、Android SDK Platform 36、Build Tools 36 和 Platform Tools。Gradle Wrapper 使用 8.14.2，Android Gradle Plugin 使用 8.10.1。

```powershell
$env:ANDROID_HOME = 'D:\dev\android-sdk'
.\scripts\build-apk.ps1
```

Windows PowerShell 默认执行策略限制脚本时：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-apk.ps1
```

首次构建会生成个人发布签名。签名密钥位于 `.signing/bilispeed-release.jks`，随机密码经 Windows DPAPI 加密保存在 `.signing/password.clixml`。保留这两个文件，后续 APK 才能覆盖安装；加密密码文件绑定当前 Windows 用户。它们和本机路径均不提交到 Git。发布 APK 关闭调试。

自行克隆构建会使用自己的签名，不能覆盖本项目 Releases 的项目签名版本。发布者需要一直保留原密钥；换电脑前需安全迁移密钥及其密码。

版本和更新仓库配置位于 version.properties。构建会生成 APK、artifacts/update.json 和 artifacts/SHA256SUMS.txt。它们必须来自同一次签名构建。

已有 Android 16 模拟器或 USB 调试设备时可同时验证：

```powershell
.\scripts\build-apk.ps1 -RunTests
```

同时连接多个设备时，用 `-DeviceSerial emulator-5580` 显式指定测试设备（编号以 `adb devices` 为准）。

可用 `-TestFilter` 精确运行测试类或方法，例如 `-TestFilter 'app.bilispeed.browser.PlaybackInstrumentationTest#largeWebViewHistoryUsesBoundedStateAndPreservesUrlAndRate'`，其余构建、签名和安装检查仍会执行。

隔离运行 `PlaybackInstrumentationTest#everyPresetChangesRealPlaybackSpeedThroughButtons` 时，可加 `-OriginalLayoutProbe` 对照电脑原版布局的实际播放计时。不同环境的结果和历史计时限制见 VALIDATION.md。

测试使用独立的测试 APK 和测试视频，覆盖真实媒体播放速度、网站重置、替换视频、iframe、Shadow DOM、自定义数值、速度持久化、全屏、后台延迟播放、批量页面更新与分享文本解析，以及电脑端链接转换、旧版偏好迁移、两列触屏布局、原版布局切换，以及更新版本、地址、哈希、包名、签名、取消、失败重试和安装文件隔离。测试媒体不会包含在交付的 APK 中。

播放器专项还覆盖单指滑动与双击、取消手势、音量和静音恢复、字幕选择、全屏自动隐藏、按住滑杆、换视频、横竖屏、竖向视频比例，以及按钮外观的即时更新、持久化与恢复默认。1.2.3 分轮验证 45 项取得通过结果，包括 320px 窄屏、真实渲染进程恢复和 B 站实站操作；账号字幕资源、实体设备和逐档实际倍速计时限制见 VALIDATION.md。

构建脚本通过 ADB 检查设备并保存/恢复原偏好及临时系统设置；测试包会复制到英文临时路径，避免 Windows 安卓工具对中文项目路径的兼容问题。结果默认保存在 `artifacts/instrumentation-tests.txt`，可用 `-TestLogName` 指定独立日志。1.3.0默认核心集合120项，字体与TalkBack复现入口见 DEVICE-TESTING.md。

## 发布后续更新

1. 在 version.properties 递增 versionCode 并更新 versionName，例如 16 / 1.3.1。
2. 修改 release-notes.md，使用原来的 .signing 密钥构建并验证 APK。
3. 提交已验证的源码，再从该提交重新构建正式 APK，确保包内的源码版本记录与发布标签一致。推送源码和标签后，发布三个 Release 附件：

~~~powershell
.\scripts\build-apk.ps1 -RunTests -DeviceSerial emulator-5580
git add .
git commit -m "Release 1.3.1"
.\scripts\build-apk.ps1
git tag v1.3.1
git push origin main v1.3.1
.\scripts\publish-release.ps1
~~~

发布脚本需要已登录的 GitHub CLI；它校验 APK 与更新信息是否一致，并创建最新正式 Release，不替换已有版本。预发布测试可用 -Draft，草稿不会进入在线更新渠道。无需把签名密钥上传 GitHub。

提交后重建可用 `scripts/compare-release-apks.ps1 -TestedApk <已验收包> -ReleaseApk <正式包>` 逐条目核对，只允许源码版本元数据不同。发布后运行 `scripts/verify-published-release.ps1` 匿名下载三个附件和latest更新信息，核对摘要、大小及原签名；正式安装仍需另行核对手机实际包。

本机若 GitHub CLI 因 HTTP/2 网络代理报 EOF，可先设置会话环境变量：$env:GODEBUG = 'http2client=0'。
